Install and set up

  1. Open the downloaded file and tap Install. Allow installs from your browser if asked.
  2. In the app, go through buttons 1 to 5 from the top.
  3. If the accessibility toggle is greyed out: Settings, Apps, Security App, menu, Allow restricted settings.
